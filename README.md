# GitHubTestCorso

## Descrizione
Questa repository serve per imparare a utilizzare Git e GitHub attraverso esercizi pratici.

## Obiettivi del corso
- Creare e modificare file.
- Controllare lo stato con `git status`.
- Preparare le modifiche con `git add`.
- Salvare le modifiche con `git commit`.
- Pubblicare i commit su GitHub con `git push`.
- Scaricare gli aggiornamenti con `git pull`.
- Creare branch e Pull Request.

## Struttura del progetto
Aggiungeremo file di testo e piccoli esempi durante le esercitazioni.

## Stato del progetto
In fase di apprendimento.
